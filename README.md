## Bungas
*Bungas é um caracol muito gente fina que tem um significado muito profundo de felicidade ao ver ele.*

`Sinônimos: caracol, caramujo, molusco, legal, bacana, divertido, impressionante, incrível, admirável, bunhas, dungas, bunfas, bunpas, calungas.`
`Antônimos: chato, ruim, péssimo, horrível, bosta, merda, lixo, fafas, fanfas, lalau, pirobolas, bangalangas, bingalingas.`

### Exemplo de uso da palavra Bungas:
* Esse livro é bem **bungas**;
* Fui brincar no quintal e encontrei um **bungas** lá;
* Caracol **bungas** girafafa fingers;
* Esse jogo é muito **bungas**.
